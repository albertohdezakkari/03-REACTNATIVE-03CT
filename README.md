# C03 · DataBridge: TypeORM con NestJS

Cuaderno de aprendizaje Full Stack con React Native + Expo, NestJS, TypeORM y PostgreSQL local.

## Repositorio del alumno

`C03-DATABRIDGE-TYPEORM-POSTGRESQL`

Cada ejercicio es una isla independiente:

```text
EJERCICIO-XX/
├── backend/
├── frontend/
└── README.md
```

## Publicación docente

Sitio estático preparado para GitHub Pages desde la rama `main`.

Archivos:
- `index.html`
- `styles.css`
- `data.js`
- `app.js`
- `.nojekyll`

El progreso del alumno se guarda mediante `localStorage`.

## Rúbrica de evaluación

La rúbrica está disponible en [rubrica/](https://albertohdezakkari.github.io/03-REACTNATIVE-03CT/rubrica/), enlazada desde el inicio y el menú del cuaderno. Incluye los 57 criterios de los diez ejercicios y sus ponderaciones, que suman 100 puntos.
