Cómo se aplica

Se conceden los puntos de las partes verificables; no es todo o nada por bloque. Se aceptan soluciones equivalentes y no se descuenta varias veces un mismo fallo por sus consecuencias.

Desde el bloque hasta 5 se puede demostrar una aplicación de lectura completa. Los datos iniciales se cargan con SQL; los formularios y POST se incorporan para alcanzar el 7. Editar y eliminar se incorporan para alcanzar el 10.

Identifica caso, correo y sesión; conserva capturas, peticiones, SQL, historial de Git Bash y SHA del commit de cierre. La explicación y las evidencias se contrastan con la ejecución real. La maqueta es una referencia funcional; no se puntúa copiar sus colores o estilos.
