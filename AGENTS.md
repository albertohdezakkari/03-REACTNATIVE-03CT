# Material público

Este repositorio solo contiene materiales de aprendizaje y repaso.

- No añadir ni publicar exámenes, preguntas reservadas, asignaciones individuales, soluciones de examen, rúbricas, correcciones ni guiones o procedimientos docentes de evaluación. Estos materiales se mantienen en GitHub privado.
- No basta con ocultar enlaces: no deben existir archivos reservados en ramas, historial, artefactos ni GitHub Pages públicos.
- Pedir confirmación explícita al profesor antes de publicar cualquier examen. La hora prevista no autoriza su publicación ni programación.
- No crear ZIP ni paquetes comprimidos.
