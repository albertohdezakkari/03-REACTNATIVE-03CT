Cómo preparar la base antes del control

  1. Obtén la base neutral desde GitHub y sigue la preparación guiada del cuaderno web.
  2. Con internet todavía disponible, ejecuta npm ci dentro de backend/ y de frontend/. Conserva node_modules en tu ordenador.
  3. En Windows usa usuario postgres, contraseña 123456, host localhost y puerto 5432. Crea control_databridge en PostgreSQL y sigue la guía paso a paso de .env: creación del archivo, explicación de variables, ejemplo para macOS y comprobación de Git.
  4. Arranca el backend y comprueba http://localhost:3000/salud. Abre la pantalla base de Expo.
  5. Desconecta internet y repite el arranque con npx --no-install expo start --offline. Si utilizas un móvil, conserva la misma red local y prueba la IP del ordenador.
  6. El jueves recibirás el enunciado concreto. La base no contiene la solución. La entrega se recogerá por el medio local que indique el profesor; no depende de GitHub o Forms durante los 90 minutos de evaluación.
