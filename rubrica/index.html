Cómo interpretar la corrección

CUMPLE

El criterio está resuelto y la evidencia permite comprobarlo.

PARCIAL

Hay partes correctas y otras incompletas. El feedback debe explicar qué falta.

NO CUMPLE

La evidencia muestra que el requisito no está resuelto.

NO VERIFICABLE

Falta información suficiente para concluir. No significa automáticamente que el trabajo sea incorrecto.

Estos estados explican el resultado; no establecen porcentajes automáticos de puntuación parcial. Deben respetarse los puntos y condiciones de cada criterio.

Reglas que debes conocer

Tu solución puede ser diferente.

Se aceptan implementaciones técnicamente equivalentes. No se exige copiar el código docente ni utilizar sus mismos nombres internos, salvo nomenclatura expresamente obligatoria.

Un error tiene una causa.

Se evita descontar varias veces por el mismo fallo. Si falta una isla completa, se valoran sus criterios sin añadir penalizaciones externas.

El código debe sostener lo que explicas.

Un README que afirma que algo funciona no sustituye su implementación. Los recursos docentes .txt no son archivos obligatorios de entrega. No se exige evidencia.md por defecto.

Leer código no es ejecutar la app.

La inspección estática permite revisar estructura y lógica. No demuestra por sí sola una ejecución de NestJS, Expo, HTTP o PostgreSQL. Si falta una comprobación, debe indicarse con claridad.

C02 y C04: nombres equivalentes.

El identificador de evaluación es C02. También se admite el nombre C04-DATABRIDGE-TYPEORM-POSTGRESQL publicado en la web para este contenido. La discrepancia entre versiones no reduce la nota.

La prueba 5/7/10 es otra actividad.

Esta rúbrica corresponde a los diez ejercicios del cuaderno completo. Los challenges de 5, 7 y 10 puntos y la ruta /challenge/ tienen una evaluación independiente.

Los límites del lector no son un fallo tuyo.

Un archivo listado pero no leído, o truncado en su parte relevante, no se considera ausente. Se indica NO VERIFICABLE y la necesidad de revisión docente.

Las credenciales se protegen.

Si aparecen credenciales reales, se recomienda revocarlas o renovarlas y no se reproducen en el feedback. No se aplica por ese único motivo un descuento no previsto en la rúbrica.

El feedback te indica cómo continuar.

Recibirás puntuación por ejercicio, aspectos correctos, mejoras y un concepto para repasar. Las observaciones deben mencionar archivos, rutas u operaciones concretas. El profesor revisa el resultado antes de devolver la calificación.
